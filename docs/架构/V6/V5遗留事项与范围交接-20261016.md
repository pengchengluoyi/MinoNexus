## 1. 本次已确认的登录规则

用户决定：`confirm_login_state` 在**本次登录提交之后**只检查一次，优先比较可用 DOM，没有可用 DOM 再比较截图；只要已离开本次提交前的登录界面，就结束登录提交确认。后续再优化实际认证状态识别。此次不再以缺少可见身份、退出入口或原业务页面为由反复确认。

- 提交前观察与本次实际派发的 submit attempt 绑定；不能使用别的用例、设备、应用或提交的参考画面。
- 同一 attempt 的比较结果复用，不为确认登录而导航、滚动、退出、重新登录或恢复原页面。
- 仍在原登录界面则报告登录未完成；比较输入缺失或执行失败则报告观察错误，不转入补证/重试循环。
- 比较 DOM 时忽略输入值、倒计时数字和焦点/键盘几何变化；截图比较不以 Toast、加载、键盘收起或错误提示作为页面切换。
- 本用例已成立的提交切换结论不会仅因时间超过 90 秒或后续页面没有登录特征而失效；退出、清理、作用域变化仍使旧结论失效。
- 账号租约本身不再强制要求观察工具验证 UI 身份。设备登录态与租约账号绑定分别处理；没有实际提交来源或 UI 身份匹配时，不把现有登录账号绑定成租用账号。
- 这是暂定的**页面切换判断**，不是认证服务已成功、账号身份已匹配或业务页面已达成的证明。日志记录 `verification_method=login_page_transition`；业务预期和严格证据准出不被自动放行。
- 运行前置对“本来是否已登录”的检查与提交后检查不同：没有本次提交前参考界面时，不能冒用页面切换证明前置。此次没有删除原业务前置。

源码：`loop/login_transition.py`、`loop/flow_block_runner_v2.py`、`loop/visual_review.py`、`loop/milestones.py`、`services/login_evidence.py`、`loop/observe/session_persist.py`、`services/resource_transition.py`。执行提示词更新至 `agent-vision-exec v33`。

已完成 25 项隔离检查，覆盖 DOM 优先、截图单次回退、无变化失败、比较错误停止、attempt/作用域绑定、已成立结论保留、失效与账号身份分离。未运行 pytest。隔离截图检查没有调用真实模型，不作为截图分支真机通过证明。
