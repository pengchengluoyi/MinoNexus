# V6 本轮源码合并记录

日期：2026-10-18。按用户“先把你的改动合并一下”，本轮先将工作区实现合入三个项目的工作树。源码合并不等于全部 V6 任务完成或正式发布。

## 范围决定

- 使用现有 admin 正常登录入口检查服务，权限和任务归属继续按用户隔离。
- 按用户决定移除 Nexus、Scout、Workbench 的升级与回退入口和执行逻辑；保留基本安装、启停以及历史维护记录。已派发、状态未知的历史维护操作不因功能取消而自动放开门禁。
- 合并时保留 MinoNexus 已有的 `server_mdns_enabled` 改动。

## 本轮实现

- 来源绑定：显式字段映射、稳定文本编号、完整快照校验、变化项 revision/job、generation 防旧回执覆盖、解绑与退役候选；不会自动删除源中消失的用例。
- Scout 来源读取：授权根目录内 CSV/XLSX、工作表选择、公式缓存检查，以及独立 Sheets 范围读取；Nexus 不直接读取用户电脑文件。源码隔离目录可显式设置 `MINO_SCOUT_DEV_HOME`，不借用正式安装目录。
- 后台来源轮询、自动编译开关、每日构建额度及等待状态；自动来源构建可复用相同输入产物，显式重编不使用该缓存捷径。
- 运行请求收据与重复提交去重，Workbench 保留受理不明请求并按原编号恢复；任务选择、策略与关闭报告保持固定。
- 设备、账号和显式共享数据域的组合事务准入，attempt/epoch/expiry 租约与续租；组合失败不会留下部分领取。
- 持久批次与 attempt 截止时间、超期终结、重启保留已完成项，仅恢复未开始项；在途项不自动重放，未知资源继续隔离。
- 账号事实分页、应用/平台/build/环境范围及有效期；复核事实不再无范围写入全局账号字段。
- Workbench 来源维护、执行资源配置、报告对比入口。不同构建/环境/版本或缺少身份事实时明确不可比，不合并两次运行结论。
