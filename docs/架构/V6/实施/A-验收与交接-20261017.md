## 初始化审计

配置必须在导入 core.paths/core.database/app 前设定。paths 导入创建目录，database 导入创建 engine；ensure_db 的 ready 仅对当前进程有效。CLI migrate 执行完整 create_all、migration 和 bootstrap，不是仅 ALTER。备份应在任何初始化前完成；不能用它在线试探正式数据。

| 步骤 | 副作用、覆盖与恢复边界 |
| --- | --- |
| create_all / additive ALTER | 新建表和缺列；新库重复启动通过，不代表历史冲突库或并发初始化通过 |
| binding_key、owner、email 回填 | 写业务行/marker，随后建立索引；email 归一化可能暴露历史冲突；不能视为纯 schema 变化 |
| DROP app_cases、FTS/索引 | 包含不可逆表删除和全文索引变更；失败向调用者传播；旧版本依赖需逐组合验证 |
| 秘密/账号文件清理 helper | 当前 migration 调用链未接入；不能宣称启动必然删文件，也不能据此承诺未来版本安全 |
| **bootstrap（单独审计）** | load_all 校验 prompt；migrate_legacy 迁移知识并移除 settings 旧字段；recovery/resource-transition seed、permission/media/account/OTP/consent/IME/check-run-env/FSM/package/empty-params 升级、flow seed、key_ref backfill、read_web_auth、skill_channel 各自可能写库。并行 B 增加 development capability 同步，归 B 所有。外层 rollback 不能撤销内部独立 Session 的提交 |
| bootstrap 覆盖规则 | flow block 已按明确序列只升不降；其他 recovery 升级仍有按内容差异覆盖的逻辑，不能宣称全部 seed 单调版本化。移除过时 guard base 初始化，不放宽 catalog writer 校验 |
| 失败与重跑 | 当前新库两次完整初始化及失败修复重试通过；旧 HEAD 完整初始化失败。自动回退准入保持 false，不以跳过 bootstrap 或异常为恢复方案 |

## 写者、活动统计与退出边界

下表是源码入口审计和 D2 交接合同，不声称 A 已实现统一排空。活动 run 为 0 不足以证明全部写者退出；进程退出后仍需核对其派发的远端工作项及未知副作用。

| 入口 | 写入/副作用 | 活动统计、停止及恢复要求 |
| --- | --- | --- |
| app lifespan 初始化/对账 | 默认用户、run 对账、租约状态 | 不计普通活动 run；启动即可能写，维护恢复不能伪装只读健康检查 |
| case_exec / case_runner normal、explore | session、run、账号/设备租约、远端动作 | 有 run 身份，但终态不等于线程停止；取消后必须等待 worker，保留未知写隔离 |
| session_store / dispatch_log / LLM 结果 | SQLite 事件、结果、文件日志 | 附着调用者且包括尾部回写；等待所有持有调用者退出，不单看 run 状态 |
| router_proxy 本地 to_thread | 非设备 executor、LLM、人审、日志 | 外层 cancel 不终止底层线程；远端派发和租约另行核对 |
| device_display_guard | 经 Router 的屏幕守护派发/日志 | 生命周期附着 run；需 stop/join，不以 daemon=True 当停止证明 |
| doc_sync loop | 网络读取、文档与同步状态 | 不包含在普通 run 数；停止调度并等待当前同步完成，异常保留结果 |
| assistant_delivery loop / on_run_finished | 外发通知、claim 和进度 | 独立任务；cancel 不证明在途外发未发生，不重放 unknown |
| case_compilation loop + keepalive | 编译 claim、产物、状态、心跳 | 持久编译任务与 run 分开；等待 run_one 和 keepalive 退出，租约过期不是线程退出证据 |
| development worker（并行 B） | 开发任务、IDE 启动和结果 | 由 B 持久任务统计；A 保留代码，不宣称完成 B 排空 |
| rAppAutomation tick | 用例/编译 job 与模型结果 | 后台 user_thread，不等同活动 run；按 job 和线程等待完成 |
| case_import preview worker / pool | 预览批次与编译状态 | 预览独立 token/job；关闭入口并等外层及池内任务结束 |
| rMcp / assistant_tools 单线程池 | 业务工具派发、收据、可能外部副作用 | 普通请求仍可能写；probe 在分发前只放行三个只读方法。Future 超时不表示内部 worker 停止 |
| node_registry / WebSocket 注册心跳 | 节点快照、连接、绑定状态 | 空闲节点仍写；关闭准入及连接，再等 handler 尾部完成 |
| node_registry IM inbound / websocket im-hold | 入站处理、业务写入、ACK | 独立线程；核对在途消息，不能把断线当未执行而重放 |
| wechat_ilink poll | 收发消息、账号及消息状态 | 条件启用的独立轮询；stop 及 join 后保留确认边界，A 未启用真实微信验收 |
| 导航采集与 HTTP 写接口 | 文件证据、导航/项目/账号等库写 | 包括非 run 请求；停止新请求并等待在途完成，恢复由原业务合同决定 |
| execution_user.user_thread | 捕获账号上下文 | 包装器自身不是独立业务任务；不能重复计数代替追踪其 target |

没有发现已接线的统一 APScheduler 调度器，不把依赖声明记作运行写者。D2 后续写者门禁改动是并行工作的新增合同，需另行实际验收，不能反写本轮静态审计为全部停止通过。
