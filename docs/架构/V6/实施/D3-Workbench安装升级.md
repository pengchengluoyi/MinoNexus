# D3：Workbench 安装升级

Workbench 独立发 GitHub Release：dist + 小型静态服务 + Python runtime。Node/npm 用于构建，不作为生产必备。启动器支持 serve/dev 的端口和 nexus-url；正式缺地址使用约定默认值，开发缺显式测试地址拒绝。

现有 vite.config.ts 提供开发代理，src/lib/config.ts 读取编译时 VITE_NEXUS_URL；需要改为初始化读取运行配置再创建 HTTP/WS 客户端。tokens.ts 当前单一键，盘点登录/退出/请求/WS读取点，按目标隔离；旧凭据不自动迁到未知目标。

CORS、WS Origin 与部署地址一起配置；不把 CORS 视为认证，不意外阻断 MCP 非浏览器客户端。运行配置不可被旧缓存遮蔽。

应用与更新助手登记同 D2，但纯静态更新只需原子切版本。HTML 与不可变资源使用不同缓存策略，旧资源 URL 在保留窗口可访问。静态路径防越界，SPA fallback 不伪装缺失资源成功。运行时更新才需停启。

验收实际浏览器请求/路由/懒加载、配置切换后重新鉴权、默认地址及错误地址、版本回退和跨主机访问。Web 项目开发地址可先在 B 交付，本阶段完成正式安装与自动更新。
