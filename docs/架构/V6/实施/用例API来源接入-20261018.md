# 用例手动导入（2026-10-18）

按用户要求，删除独立的「来源与更新」页面，只保留项目用例页的「导入」入口。
删除后台定时读取循环、失败退避调度、变化后自动解析和每日预算释放逻辑，不保留调度开关。
历史用例、绑定和收据保留；数据库中的历史调度列仅为兼容旧库而保留，无调度消费者。

## 使用

1. 项目 → 用例 → 导入，选择「本地文件」「飞书表格」或「用例接口」。
2. 本地文件直接选择 Excel/CSV。多工作表文件仍支持选择工作表，UTF-8 CSV 按中文编码读取。
3. 飞书粘贴选中工作表的链接（含 `sheet` 参数），确认读取范围，点击「读取用例」。
   使用本人在线 Scout 的既有飞书接入；默认范围 `A1:Z1000`，其他范围手动修改。
4. 用例接口使用节点已有的服务账号，点击「读取项目列表」，选择整个项目或指定会话，
   再点击「读取用例」。单节点自动选择，多节点按名称选择，无需输入节点 ID。
5. 三种来源统一进入字段核对、解析预览、冲突审阅和确认导入。没有需求分组时输入名称，
   点击「添加分组」即可继续，默认名称「导入用例」。

只在用户点击时读取。读取不会创建来源配置、绑定、定时任务，也不会自动写用例。
原始表格核对与预览失败保留已有导入内容。服务账号在设置的节点接入配置中管理，
密码由 Scout 现有凭据管理保存，token 只存在于登录调用的内存。

## API 和数据语义

- Nexus 新增项目范围 `cases/import/sources` 和 `cases/import/read-source`，要求维护权限，
  节点必须属于当前认证账号，复用现有 `node.source_read` 协议，无通信协议变更。
- 用例服务登录 `POST /api/auth/login`，发现 `GET /api/projects`、`GET /api/sessions`，
  读取 `GET /api/cases` 或 `GET /api/sessions/{id}/cases`。Bearer 与 `X-Project-Id` 沿用服务合同。
- API 固定字段转换为可核对的表格，导入编号为 `api-{远端项目ID}-{不可变id}`，
  不使用跨会话可能重复的 `case_number` 作主键。步骤列表转为多行文本。
- `case_number/priority/remarks/session_id/session_title/test_result/created_at` 在读取的原始
  表格中供参考，未映射的列不写入本地用例。远端结果不写本地执行结果。
- 远端鉴权失败、重定向、重复 ID、缺关键字段、范围不符、超限、不完整或读取时变化均拒绝，
  保留现有用例。空列表提示没有可导入内容，不删除或标记本地用例。
- 历史来源接口只保留手动兼容和历史查询；调度参数从请求与返回中移除。
