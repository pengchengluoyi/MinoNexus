# 三仓本地改动整合与发布

本次将原始三个仓库的未提交改动与已发布 main 合并，而不是用旧工作目录覆盖发布代码。原始改动有独立快照和备份；合并提交同时保留两条历史。

整合范围：应用开发环境配置与准备任务、IDE HTTP/SSE 接入、APK 身份核验与安装回执、Scout 固定版本更新与恢复、Workbench 开发环境面板。保留新版跨平台安装、环境隔离和 GitHub 固定版本下载。

源码开发仅监听本机：Nexus 50101、Workbench 60101；正式安装使用 Nexus 50104、Workbench 60104 并支持局域网。Scout 只连接 Nexus，不新增业务监听端口。Workbench 安装后默认打开，`mino-workbench open` 可启动并打开页面。Windows 后台服务的两层进程均采用无可见控制台方式启动。

三仓产品文案、示例及新文件名称统一使用 Mino。读取旧安装文件格式的兼容分支保留，不更名现有用户数据。历史验收文档的品牌示例已统一；其中历史端口与旧验收结论不代表当前发布状态。

本地验收：协议源码与协议文档两仓一致；修改的 Python 源码语法检查通过；Workbench 类型检查、lint、构建通过；隔离 Nexus 与真实浏览器完成登录、开发环境配置保存与刷新回读。未连接用户的真实 IDE、Android 设备或修改生产数据；这些外部场景不因编译通过而被宣称已实测。

发布由 GitHub Actions 在各系统原生构建。Nexus/Workbench 验收四个原生平台；Scout 当前发布 macOS arm64 和 Windows x64。正式 Release 从成功 main 构建的同一批产物发布，不上传本地构建包。具体执行结果以仓库 Actions 和 Release 为准。

普通应用更新不替换稳定 launcher；旧安装的启动器修复仍需独立迁移。Windows 安装时使用管理员权限、运行时使用普通权限的访问错误尚缺具体路径及完整错误，不能宣称已解决。
