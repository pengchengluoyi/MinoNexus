## 已有能力，不重复列为从零开发

- 页面资料复核、影响分析、定向重验、问题修复/复发趋势。
- 编译指标：明确失败率、证据确认复用率、平均/P95 时延与缺失样本；平台/时间筛选和浏览器验收已完成。
- 资源组合准入、持久预算、资源等待截止守卫、安全复跑谱系、不可比报告分开。
- 仅恢复未开始项的重启策略及未知写隔离；局部验证不替代 V6-R4。
- 手动安装发布链与基本启停；与已取消的产品自动升级/回退不同。
