## 本批剔除的降级/兜底位置

1. `core/paths.py:get_app_data_dir`：新路径不可用时自动选历史路径。
2. `runtime/session_gate.py:clamp_case_scene`：非法/缺失平台自动 Android。
3. `runtime/platform_gate.py`：未知平台声明当不限平台、Web 自动改桌面原生的相关路径。
4. `services/project_env.py:resolve_surface_id`：渠道候选不明确仍选首个、跨平台猜测。
5. `services/project_env.py:resolve_profile_name/resolve_run_env_profile`：显式环境错误转默认/首个。
6. `services/project_env.py:env_from_project_row`：项目空配置取第一应用。
7. `services/project_store.py:_owner_from/_root`：缺归属用管理员、读取时补写。
8. `services/nav_calibration_store.py:save_draft/read_draft/delete_draft/promote_draft`：SQLite 异常转 JSON，读取/发布时迁移旧 JSON。现在仅用数据库；异常上抛。
9. `services/nav_target_scope.py:resolve_app_target_scope`：读取或合同异常被吞掉后猜另一个来源。现在异常上抛，已配置作用域不得与请求冲突。
10. `services/nav_target_scope.py:infer_foreground/turn_matches_scope`：无实际前台证据仍当目标应用、仅有存储的目标标签就视为匹配。
11. `loop/navigation_policy.py:dispatch_pending`：缺少 NavFSM 自动切 DOM/视觉。现在返回 blocked / navigation_configuration_required。

这份清单是本批已改范围，不是全仓降级清零声明。

## 验证与限制

- 本批变更 Python 文件静态编译通过；删除函数的名称/导入引用检查通过。
- 70 项纯函数检查通过：四平台与覆盖声明、非法平台、状态口径、恶意相似域名/端口/凭证 URL、导航证据缺失、渠道歧义、无效环境、管理员兜底等。
- 未新增仓库单元测试，未执行 pytest，未连接业务库执行验证，未删除或迁移业务数据。
- 未重启 IDE 管理的服务，也未启动替代服务；真实执行验收仍须使用重载后产生的 session_events + session_meta，不能用纯函数检查代替。
- 老配置可能开始明确报错、旧目录数据不再自动出现、未迁移旧号池账号不再自动导入。这是删除兼容后的行为；原始数据仍保留，本文不授权清库。
- 普通执行模式目前仍叫 `legacy`；不能仅凭名称删除，它仍承载正常 Agent 执行。尚未改为 `agent`，也未改协议载荷。
