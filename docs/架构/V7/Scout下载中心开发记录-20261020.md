# Scout 下载中心首期开发记录

日期：2026-10-20。状态：首期源码已实现；隔离真实安装通过；现有运行环境的 HTTP 和浏览器联调待验收。

## 实现范围

- Scout：六类只读事实；飞书/Meego 异步安装；按 Nexus origin + owner 保存 SQLite 任务回执；同 task_id 幂等；进程重启后未完成任务标记中断。新旧安装与移除按插件互斥，其他组件不进入 CLI 锁。
- Nexus：三个下载中心接口；模块级请求模型；node_tool_tasks 投影；同账号 operation_id 唯一；事务内先写 pending 再派发；未知应答只查询原任务；显式同 ID 重试须得到不存在回执且身份匹配。仅本人节点可执行，离线仍可读任务与标过期快照。
- Workbench：pane=downloads 页签、六类组件表、安装任务区；账号/服务/节点隔离的查询键和请求编号；活动约 2 秒、闲时约 15 秒查询；配置页快捷安装接入同一接口，保留配置草稿，安装结束后另行保存；旧节点保留原同步安装行为。
- 两仓 protocol.py、PROTOCOL.md 完整文本一致；新增 tool_tasks_version=1 显式合同、三个短命令与 progress.task_id。未上报合同的节点降级为只读，不按版本号猜测。
- 当前数据库已改为严格结构校验，原方案所述通用 additive 迁移已不存在。因此只对新增 node_tool_tasks 提供受限建表；其他表缺失或列漂移仍拒绝启动，不自动修复现有业务库。
- Scout 核心自动升级继续拒绝；Chromium、ADB Keyboard、LangBot 没有新增安装、更新或清理入口。未更改 heavy_deps、adb_ime、langbot_host 的安装策略。
