## 2026-10-20 18:51 Scout 注册后立即断线回归

根因：Nexus 要求每帧完整 executor 快照，但 Scout 仅在定时心跳补 executor_snapshot_version=1 与 executors；注册 ACK 后立即发出的 ScoutCore.heartbeat 仍为 0/None，触发 1008。插件通知和停止前发送入口也存在同样遗漏。此前“请升级 Scout”的通用提示掩盖了实际字段错误。

修复：完整快照及其 capability_revision 移到 ScoutCore.heartbeat 统一构造；定时入口复用，desktop 状态更新后重新计算 revision；停止前采集移到工作线程。Nexus 保留严格校验，移除校验后的不可达旧快照分支，并输出具体合同错误码。两仓协议文档同步修正增量快照旧表述。

验证采用本地无设备合同检查与跨端协议 round-trip，不运行 pytest，不修改真实业务库，不启动或接管 IDE 业务进程。源码生效仍需在 PyCharm 重载 Scout 和 Nexus，以注册后持续超过心跳周期且无 1008 的现场日志确认；真实跑批验收仍未完成。
