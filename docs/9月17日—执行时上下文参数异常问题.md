# 9月17日 — 执行时上下文参数异常

**问题类型**：注入 agent-decide / assert 的 **运行上下文参数** 异常——重复拼接、缺失关键字段、或与真实屏态/前置操作不一致，导致 decide 与校验偏离。  
**优先级**：**P0/P1**（登录流、清缓存后首步）

---

## 0. 参数字段一览（真源分工）

| 字段 / 槽 | 来源 | 用途 |
|-----------|------|------|
| `RunContext.session_fact` | `inspect-session` 成功后 `stamp_session_observation` | task 内结构化 session 结论 |
| `RunContext.session_dirty` | `clear_app_cache` / 杀进程等 | **登录态不可信**，须强制 refresh |
| `RunContext.case_scene.required_session` | 用例 CaseScene | guest / logged_in 合同 |
| `inspect_slots["session_block"]` | inspect-session 文本 + merge | 模型可读 session 段落 |
| `inspect_slots["session_execution"]` | `execution_context_session_line` | 紧凑字段：`session_dirty` / `required_session` / `task_session` |
| `assert_session_context` | check 并入 knowledge | 校验登录预期时钳制误判 |

```text
refresh / stamp → session_fact
每 turn merge → session_block（去重）
每 turn       → session_execution（结构化一行）
phase→do 且 session_dirty → force refresh_session_block
```

---

## 1. session_block 重复拼接（已修）

### 1.1 现象

`session=logged_out ... source=run_context |` 同一行重复多段（`cr-77e8880d7ac1` 类 trace）。

### 1.2 根因

`effective_session_block` 曾对 `logged_out` 每 turn prepend，旧 block 已含 run_context → `|` 膨胀。

### 1.3 修复

同 session 值已出现在 slot → **不再 prepend**；`line in block` → 跳过。

---

## 2. 清缓存 / 隐私弹窗后「忘记登录态」（`case-c8cee4b9`）

### 2.1 现象

前置 `clear_app_cache` → 点隐私/同意 → 进入 do 后仍按 **已登录** 思维点「我的」查登录，与 `required_session=guest` 矛盾。

### 2.2 根因

| # | 说明 |
|---|------|
| 1 | 清缓存后 `session_dirty=True`，但 **未** 在 enter do 时强制 `refresh_session_block` |
| 2 | `session_fact` 仍为清缓存前结论或空，decide 缺 **guest 合同** |
| 3 | 模型见 Tab「我的」即假设已登录，未读 `session_execution` |

### 2.3 已落地

| 改动 | 行为 |
|------|------|
| `mark_session_dirty(clear_app_cache)` | 已有 |
| `phase_enter:do` + `session_dirty` | **force** `refresh_session_block`，再清 dirty |
| `session_execution` 槽 | 显式 `session_dirty` / `required_session` / `task_session` |
| `assert_session_context` | logged_out vs「已登录」expected 钳制文案 |

**验收**：清缓存后首条 do turn 的 trace 含 refresh inspect-session；`session_execution` 中 `session_dirty=false` 且 `task_session=guest|logged_out` 与屏一致。
