# MinoNexus 开发手册

面向在本仓库改代码、联调 Studio / Scout、用 Agent 辅助排查的同学。**与** [排查手册](排查手册/排查手册.md)（按 ID 查日志）**互补**：本文规定日常开发纪律，避免把个人调试写进真库。

---

## 1. 数据目录与真源

| 项 | 说明 |
|---|---|
| 默认路径 | `~/.mino-nexus/`（可用环境变量 `MINO_NEXUS_DATA_DIR` 覆盖） |
| 业务库 | `mino.db`（项目、号池、设置、能力目录、跑批元数据等） |
| 约定 | 本机这份库常等同「个人/团队测试环境真源」，**不是**可随意灌脏数据的沙箱 |

表结构与路径详见 [基础框架/DATA_MODEL.md](基础框架/DATA_MODEL.md)。

---

## 2. 硬约束：调试不得直接改库

**无论人工还是 Coding Agent，在排查、验证、复现问题时，一律不得对 `mino.db`（及同目录下业务数据）做写入类操作。**

禁止包括但不限于：

- `sqlite3 mino.db` 下的 `INSERT` / `UPDATE` / `DELETE` / `REPLACE` / `DROP` / `ALTER`（只读 `SELECT` / `.schema` / `PRAGMA` 除外）
- 在终端或脚本里调用 `session_scope()`、`upsert_one`、`save_one_test_account`、`run_store.put` 等**落库 API** 做「试一下能不能存」
- 复制、覆盖、删除整个 `mino.db` 或 `~/.mino-nexus`（除非本人明确要做备份恢复，且与当前调试无关）
- 为验证逻辑而批量创建号池账号、项目、跑批记录等**污染性**数据

允许：

- **只读**查库（对照 `session_events`、号池行数等），见 [排查手册/01-Session-Log与数据库.md](排查手册/01-Session-Log与数据库.md)
- 走 **HTTP API**（Studio / Console 已登录会话），与真实用户路径一致
- 单元测试使用 **临时库** 或 mock（测试进程内 `data_dir` 指向临时目录，测完即弃）
- 只读调用 `python3 -c` 引用 **纯函数**（解析、编译、无 `session_scope` 的路径）

**原因**：Agent 在 shell 里「复现 bug」时很容易往号池、任务表插入半拉子数据；列表里会出现重复邮箱、`*@g.com` 占位账号、与业务无关的 `acc_*`，且难以区分是产品问题还是调试残留。

## 3. 推荐的验证方式

| 目的 | 做法 |
|---|---|
| 改 Nexus 逻辑 | 起本地 `mino-nexus`，用 Studio 点路径；或 `curl` 带 Bearer（与 [HTTP.md](基础框架/HTTP.md) 一致） |
| 改号池 / 环境 | Studio **账号管理**、**项目环境** 页保存；不要 shell 直写 `pool_accounts` |
| 改协议 | golden fixture + 两仓 `protocol.py` round-trip（见 [PROTOCOL.md](基础框架/PROTOCOL.md)） |
| 必须自动化 | 在 `tests/` 或脚本里把 `MINO_NEXUS_DATA_DIR` 指到 **临时目录**，或在 PR 说明里写清「未动共享库」 |

需要「空库」时：用**新的** `MINO_NEXUS_DATA_DIR` 启动 Nexus，而不是在现有库里删表清数据（除非本人运维操作）。

---

## 4. 误写入脏数据时怎么清理

1. **优先 Studio**：项目 → 资源 → 账号管理，删除明确是调试用的行（如 `test1@g.com`、`test2@g.com`、`acc_testdebug01`、重复 Gmail 别名等）。
2. **单条删除 API**：`DELETE /project/{project_id}/accounts/{account_id}`（与 Studio 同权，需登录）。
3. **禁止**把「清脏数据」交给 Agent 在 shell 里执行 `DELETE FROM pool_accounts …`，除非**你本人**明确要求且已备份。

号池真源是表 `pool_accounts` / `pool_account_facets`（见 DATA_MODEL）；删行只影响对应 `acc_*`，不会动项目环境 JSON 里的 `gmail_inbox` 等配置。

## 5. Agent / 协作者自检清单

改代码或跑命令前自问：

- [ ] 这条命令会不会 `commit` 到 `~/.mino-nexus/mino.db`？
- [ ] 能否改成只读查询或临时 `data_dir`？
- [ ] 能否用已有 HTTP 接口代替 Python 一行 `save_*`？

PR 描述中若动过本机共享库，应写明「已手工清理号池 / 未写库」。
