## 1. 设计目标（相对「小丑」现状）

| 问题 | A″ 定稿 |
|------|---------|
| 9 列空竖条、`zoomToFit` 挤右侧 | **自由画布**：块 + 游离页 **固定坐标**，整体 `zoomToFit` 居中 |
| 块拉满画布宽 | 逻辑块 **bbox 随块内页数收缩**（横向 DAG，一页一行高） |

| 线型与 driver 无关 | **`manual` 实线**；**`auto` / `system` 虚线**（对齐 §1.2 `transition.driver`） |

## 2. 画布元素

### 2.1 逻辑块（`flow_block`）

- 圆角容器 + 标题 = `display_name`（可来自文档/用例/人工，见 PRD §1.3）。
- 块内页面：**横向排列**，顺序 = `state_ids` 流序。
- 块 **不** 再使用「步数 × 520px 竖条空壳」。

### 2.2 游离页（无 `flow_block_id`）

- Tab 根、首页枢纽、仅偶发访问的页：**只有线框节点**，无块框。
- 标签可显「游离页」（Studio 可选）。

### 2.3 页面节点

- 本体 = **`NavFsmWireframe`**（regions 色块 + 可选 capture）；架构 Tab 用 `archCanvas`，不叠控件长文案。
- 标题 = display name，在节点上方/下方小字。
- **热点**：参与连线的 region 上显示 **小圆点**（`RGConnectTarget`，`targetType: NodePoint`）。

## 3. 连线规则（= §6.1 UI 体现）

### 3.1 锚点（relation-graph ≥3.1）

| 层级 | 字段 / 实现 |
|------|-------------|
| 数据 | `meta.from_hotspot_id`；Nexus `_annotate_wireframes_from_edges` 写 `region.nav_to` |
| Studio | `hotspotTargetId(stateId, regionKey)` + **`RGConnectTarget`** |
| 线图 | **`jsonData.fakeLines`**：`isFakeLine: true`，`fromType: NodePoint`，`from: targetId`，`toType: node`，`to: stateId` |
| 禁止 | `fromType: HTMLElementId`（RG 3.x 已废弃，线会静默不画） |
| 禁止 | 架构 nav 默认 **禁止** 仅节点边框 `left/right`（无热点时 Studio 合成 `nav_hint` region） |

### 3.2 线型与 `transition.driver`

| driver | 线型 | 颜色（架构图） |
|--------|------|----------------|
| `manual` | **实线** | accent `#1d4ed8` |
| `auto` | **虚线** | 次要色 + 标签「· auto」 |
| `system` | **虚线** | 同 auto 或略偏橙（返回键） |
| `unknown` | 实线或细虚线 | 待 Studio 改 driver |

**Studio 展示（2026-09-16 增补）**

| 规则 | 行为 |
|------|------|
| `manual` | 蓝实线；起点 **线框热点**（`fakeLines` / NodePoint） |
| `auto` / `system` | 蓝/橙 **虚线**；起点 **源页底边**（页级锚点，不绑具体组件） |
| `reverse` | 橙虚线；同 `system` 用页级锚点 |
| 方向 | 线标签 + **终点箭头**（`showEndArrow`）；架构 Tab 顶部图例 |

**说明**：`relation=weak` 与 driver 正交；弱关系可用 **浅色**，Tab 点击仍为 `manual` 实线。

### 3.3 路径形状

- 架构图默认 **贝塞尔曲线**（`RGLineShape.StandardCurve` = 6）。
- 块内、跨块、游离页之间 **同一套路由**（含 `fakeLines`）。

## 4. 布局算法（Nexus → `meta.studio_layout`）

1. **`_pick_display_blocks`**：最多 6 块展示，优先步数多、session 命中高；**块内 atlas 至少 2 个 state** 才进布局块。
2. **块内**：`x += COL_STEP` 横向排 `state_ids`；块 region 随 bbox 收缩。
3. **游离页**：不在展示块中的 state → `flow_block_id: ""`；布局写在块阵列 **右侧单列**，间距 ≥28px。
4. **碰撞**：块 bbox 与游离页 bbox **最小间距 ≥ 36px**（迭代推开）。
5. **Studio 壳**：`buildFlowBlockShellNodes` 仅 **≥2 页** 同 `flow_block_id`；写 layout 前清空单页 `flow_block_id`。
6. **坐标归拢**：layout 完成后整体平移到画布 `(48,48)` 起。

## 7. 验收（Studio 架构 Atlas）

1. 无 **空竖条** 占满列高；块宽随页数变化。  
2. 游离 Tab 页 **无块框**，与块 **不重叠**（≥36px）。  
3. 至少一条 nav 边从 **线框内热点** 出发（`fakeLines`，非整节点左缘）。  
4. 下载类 **auto** 边为 **虚线**；点击 **manual** 为 **实线**。  
5. `zoomToFit` 后主体在视口 **中央**。  
6. 浏览器控制台 **无** `[relation-graph] HTMLElementId is no longer supported`。
