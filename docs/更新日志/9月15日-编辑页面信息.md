# 9月15日 — 架构「编辑页面」弹窗字段说明

分析对象：MinoStudio 导航 → **架构** 页，悬停节点 → **编辑** 打开的 `NavGraphInspectDialog`（非配置 Tab 侧栏 JSON）。

---

## 0. 这个弹窗在改什么

弹窗编辑的是 **NavFSM 上的一个 state（屏态节点）**，不是单帧截图本身。

- **图上节点** 来自 `GET /nav-fsm/{app_id}/screen-atlas` 合成的 `doc.states[]`（`build_atlas` 聚类结果 + 草稿 meta 叠加）。
- **保存** 会：
  1. 更新当前画布上的 `graphDoc`（立即看到改名/别名）；
  2. 架构模式下调用 `PATCH /nav-fsm/{app_id}/states/{state_id}/labels` 写入 **draft NavFSM** 的 `meta`；
  3. 刷新 atlas（`loadScreenAtlas`），使后续跑批 / `fsm_navigate` 解析用到新名称。

**不会**在保存时改：`identify.required` 信号块、guards、边 `execute`、线框 regions（除非展开「高级 JSON」整段替换）。

## 1. 当前表单字段一览

| UI 字段 | 写入位置 | 用途 | 谁消费 |
|---|---|---|---|
| **状态 ID** | `state.id`（只读展示） | 图内唯一键 | localize、最短路、`fsm_navigate` |
| **采集次数** | `meta.visit_count`（只读） | 同骨骼命中次数 | 判断是否重复节点 |
| **推断角色** | `meta.inferred_role`（只读） | 布局启发式 | 与手动 **页面角色** 对照 |
| **页面名称** | `meta.display_name` | 架构图卡片标题 | Studio、`fsm_navigate` 相似度 |
| **顶栏文案** | `meta.header_title` / `meta.chrome_texts` | 采集顶栏短文案（**不参与分桶**） | 展示、辅助起名；可加入别名 |
| **别名** | `meta.aliases[]` | 大模型口语同义词 | `nav_state_resolve` |
| **Tab** | `meta.tab` | 底栏 Tab 文案（展示/辅助） | 架构副标题 |
| **页面角色** | `meta.page_role` | 覆盖展示用角色标签 | 图副标题；不参与骨骼分桶 |
| **合并到本页** | `meta.atlas_state_remap`（服务端） | 隐藏重复节点 | `POST .../atlas-merge-states` |
| **类型** | `state.kind` | `page` / `dialog` | NavFSM 校验 |
| **Tab 入口** | `state.entry` | Tab 入口屏 | 关系图布局 |
| **高级 JSON** | 整段 `state` | identify、guards 等 | 熟手 / 校准 |

### 1.1 「页面角色」是什么？

**不是**业务菜单里的「角色权限」，而是 **导航语义分类**，与 `mino_nexus/services/nav_layout.py` 中 `semantic_page_role` 对齐：

| 值 | 含义 | 典型屏 |
|---|---|---|
| `feed` | 信息流 / 列表 / 双列 feed | 灵感流、商品列表 |
| `profile` | 个人主页、统计块多 | 我的、作品集概览 |
| `detail` | 有返回、顶栏标题的子页 | 3D 预览、地址管理 |
| `main` | 其它子页 | 未归入上三类的 Tab 内页 |

**留空（推荐）**：跑批时仍按 **当帧 hierarchy 推断** 写入 `meta.inferred_role`；**架构分桶已改为应用骨骼**，`page_role` 仅影响展示。  
仅在你要 **固定展示标签** 时再填。

### 1.2 别名与「拍摄页 / 拍照页」

`fsm_navigate` 收到自然语言 `from_state` / `to_state` 时：

1. 先匹配 `state_id`、Tab 文案；
2. 再对 `display_name` + **aliases** 做相似度；
3. `from` 还需 **当前屏 localize 分数** 印证（见 `nav_state_resolve.py`）。

因此编辑页应把团队口语（「拍照页」「手办详情页」）放进 **别名**，与架构 **页面名称**（较短展示名）分工。

## 2. 弹窗里还没有、但 NavFSM 里存在的内容

以下仍在 **state JSON** 里，默认不在表单中展示；需 **高级 JSON** 或后续表单迭代：

| 块 | 作用 | 建议后续 UI |
|---|---|---|
| `identify.required[]` | localize 信号：tab_bar、layout_framework、text_landmarks | 分信号表格 + 校准占位符提示 |
| `guards` | 弹窗、登录、权限守卫 | 与 guards 目录联动，只读 + 跳转 |
| `wiki_ref` | 链到知识库 | 选择器 |
| `meta.visit_count` | 采集命中次数 | 只读统计 |
| `meta.chrome` / `meta.chrome_texts` | 采集到的顶栏短文案（**不参与分桶**，见重复展示文档 §8.5） | 表单 **顶栏文案** 一行展示，可辅助起名/改展示名 |
| 边 `execute` / `effect_assert` | 怎么点、怎么验 | 在 **边** 上编辑，不在页弹窗 |

线框 `meta.state_wireframes` / 节点 `data.wireframe` 来自采集，**不在此弹窗修改**（避免与被动采集真源冲突）。

## 3. 保存行为（2026-09-15 后）

| 步骤 | 行为 |
|---|---|
| 点 **保存** | 合并表单 → `state` 对象；关闭弹窗 |
| 画布 | `update:doc` 更新本地 `graphDoc` |
| 服务端 | `patch-state` → `PATCH .../labels`（`display_name`、`aliases`） |
| 刷新 | `loadScreenAtlas` 重拉图谱 |

已去掉 **「应用」**；不再区分「只改画布不落库」。

**注意**：仅拖拽新增 **手动跳转边** 时仍走 `putAtlasManualEdges`，不会批量写所有 state 的 meta。
