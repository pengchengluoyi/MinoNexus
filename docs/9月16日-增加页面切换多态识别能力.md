# 9月16日 — 增加页面切换多态识别能力（方案 v2）

**背景**：Atlas **v9 粗 lane + 桶内 Jaccard**（`nav_app_skeleton`、`9月15日-架构聚类过并过拆复盘.md`）。仍存在的问题：动态区域 **过拆**、布局维度未区分、少采集时 **localize 过自信**。

**关联**：方案一 [`9月16日-用例执行调用fsmnavigate能力异常.md`](9月16日-用例执行调用fsmnavigate能力异常.md)（`target_page`、VLM hierarchy、degraded 降权）。

**优先级**：**M1/M2 与方案一 P0 并行开发**；Studio M3、VLM Job M4 可跟进。

---

## 0. 目标

- **结构 hash 为主、文本为辅**（借鉴探索测试思路，**不改变** v9 lane 方向）：聚类与 morph 判定优先 **壳层/几何/可点击抽象**，不把每个 feed cell 当成独立 state。  
- **多态 morph**：壳层不变、内容区变 → 同一 `page.sk*` 下的 `meta.morphs[]`，不增主节点。  
- **视口维度**：除有限/无限 **高度**，同样区分有限/无限 **宽度**（横滑 pager、全宽 vs 分栏）。  
- **证据分层**：`evidence_tier` + `layout_extent` 驱动 localize 封顶与 assist「参考意见」。

**定位**：应用导航图是 **逻辑页 + 可点击抽象 + 观测边**，不是物理地图 GPS；与方案一「逻辑页 `target_page`」一致。

---

## 1. 概念模型

### 1.1 逻辑页 / morph / 可点击抽象

| 概念 | 定义 | state_id |
|------|------|----------|
| **逻辑页** | 用户心智上的一屏（lane + 壳层稳定） | `page.sk{hash}` |
| **morph** | 同逻辑页，**内容区**线框抖动（轮播、feed 换卡） | 不占新主 id；`meta.morphs[]` |
| **可点击抽象** | 导航边上的 **一类**交互（底栏槽位、返回、列表入口），不是每个 cell | 边 `execute.target_page` + hotspot，**无** `page.sk` per cell |

**揉入规则（来自探索测试，非改方向）**：

1. Stage1 lane 仍用 `skeleton_fp_from_turn`（surface/kind/cols/scroll）。  
2. Stage2 Jaccard 合并；**morph 带** `[0.35, 0.65)` 且 `chrome_fp` 相同 → **不拆 `*-sN`**，记入 morph。  
3. `infinite_feed` / 横滑：**结构槽位**进线框，**cell 文案**不进聚类键。  
4. 文本 landmarks 仅作 **localize 辅信号**，不作为新 state 的主键。

### 1.2 视口：`layout_extent`（高 + 宽）

在 `layout_class` 之上增加 **`layout_extent`**（写入 `state.meta`）：

| 字段 | 取值 | 含义（结构信号） |
|------|------|------------------|
| `height` | `finite` / `infinite` | 纵向：固定槽位列表 vs 持续追加流 |
| `width` | `finite` / `infinite` | 横向：单栏全宽 vs ViewPager/横滑多屏 |
| `layout_class` | `fixed_viewport` / `infinite_feed` / `horizontal_pager` / `transient_overlay` / `unknown` | 由 extent + `framework.kind` + scroll 语义推导 |

示例：

- **我的**：`height=finite`（行槽固定，可纵向滚但结构重复）、`width=finite` → `fixed_viewport`。  
- **双列首页**：`height=infinite`、`width=finite` → `infinite_feed`。  
- **全屏横滑 Banner 占主导**：`width=infinite` 或 `horizontal_pager`；morph 记轮播帧，不拆页。  
- **分栏平板态**（若采集到）：`width=finite` + 多列 → 仍 `infinite_feed` 或 `fixed_viewport` 由列槽是否固定决定。

实现模块：`mino_nexus/services/nav_viewport.py`（`classify_viewport_extent`）。

### 1.3 架构图展示（Studio，M3）

| layout_class | 展示 |
|--------------|------|
| `fixed_viewport` | 全屏线框 + 滚动区虚线 |
| `infinite_feed` | 列槽网格 +「内容动态」 |
| `horizontal_pager` | 壳层 + 横向「多态」标记，不画每一页 cell |

## 2. 动态组件过拆（M2）

### 2.1 现象

Jaccard &lt; `WIRE_FRAME_MERGE_JACCARD` → `*-sN` 爆炸；轮播/横滑误拆。

### 2.2 规则

1. **`chrome_fp`**：`shell_cluster_signature(wireframe)`（已有 `nav_app_skeleton`）。  
2. **Morph 带**：同 `chrome_fp`、同 `framework.kind`，内容 Jaccard ∈ `[MORPH_JACCARD_MIN, WIRE_FRAME_MERGE_JACCARD)` → 合并 morph，**不新建** `page.sk*-sN`。  
3. **边**：morph 间 **不增** nav 边；`meta.observed_content_swaps++`。  
4. **壳层变**（`has_back`、kind 变、lane 变）→ 仍 **新主节点**。

### 2.3 VLM（M4，可选）

ambiguous 时 Job 输出 `same_page_morph | split_page` → pin；**不**自动改 state_id。

### 2.4 验收

- 轮播连滑 5 帧：主节点 +1，`morph_count≥4`。  
- 真换页：仍新 `page.sk*`。

## 3. 证据分层与导航置信（M1）

### 3.1 `evidence_tier`

由 **逻辑页** `visit_count`、**独立 session 数**、`morph_count`（不计入 visit 膨胀）合成：`low | medium | high`。

### 3.2 localize 封顶（`nav_localize.apply_evidence_policy`）

| 条件 | 行为 |
|------|------|
| `degraded=true`（hierarchy 弱） | 置信封顶 **0.72**；`band` 最高 `explore`；脚注「结构定位，待 hierarchy/VLM 印证」 |
| `evidence_tier=low` 且 `layout_class=infinite_feed` | 封顶 **0.55**，`band≤explore` |
| `extent.width=infinite`（横滑）且 low tier | 封顶 **0.60** |
| `meta.nav_stable=true`（per-app 配置，非代码 Tab 表）且 `fixed_viewport` | 少采集仍可封顶 **0.85** |
| `evidence_tier=high` | 维持现有 band 阈值 |

与方案一：**degraded 时骨骼单独 100% 禁止**；VLM `vlm_hierarchy` 融合后另计（`vlm_landmarks`）。

### 3.3 assist / fsm_navigate

- `band=explore` 或 `evidence_tier=low`：【路线】前缀 **「参考意见，非确证」**。  
- 失败仍 **declined** + `nav_attempt`（方案一）。

## 4. 方案外卡点（按 v1 评审结论实施）

| 卡点 | 对策 |
|------|------|
| 跨用例深层栈、图无边 | 补采 / `press_back` / `recover_restart`；assist 明示无 nav 边 |
| `goal_state_id` 与展示名不一致 | case 绑定 `page.sk*` 或别名表 |
| 边无 `target_page`/tap 编译 | `_hydrate_atlas_edge_execute` + `target_page` 迁移 |
| 旧 session `localized.chosen=page.tab_*` | skeleton 模式不灌 Tab 节点；remap turn_ref |
| morph 过并 | Studio split + VLM M4 |
| 多 App 命名成本 | Console 导入 + 模板 |

**不做**：Page Object 式纯人工图（业界 1）、纯录制流（2）、强依赖 App 文案白名单（4）。
