## 4. 按归类展开（该怎么动）

### 1. 用例写错了 / 与 App 真值不一致

- 预期文案与界面 **同义不同字**（3D空间 / 3D预览、生成中 / 详情页）。
- **新用户 + 清缓存** 仍假设「点我的 → 全屏登录」；实际常 **Feed + 半屏/拍摄链**。
- 步骤顺序：prep 不应依赖「先进登录页再跑业务」（c8cee 类）。
- **动作**：Console 改 `expected` / instruction；或 AppIntel 写清「登录成功后默认路由」。

### 2. 账号申请错了

- 本轮 **lease / get_otp / env_fixed** 多数成功；**2** 类不是主矛盾。
- 若出现「老用户/新用户」与前置不符，查 **env 标签 + case_scene**，不是 Nexus 登录宏本身。

### 3. Nexus

- **已修**：逻辑块草稿、系统弹窗 router、router 本地 cap、input_text 补全、login/input_fill 意图、logout 两步。
- **仍 open**：
  - FSM **口语 state / Tab fallback**（禁止模型自造「首页」Tab；L1 降级 tap 真实 Tab 名）。
  - **signal_done 前 step_effect / 详情探针**（减少假收工）。
  - **skip_repeat** 与 **业务 intent**（仅 tap 次数达标但未到详情）。
  - LLM **no_tool_calls 第二轮 JSON 降级**（本轮已加）。

### 4. Scout

- **`tap_element 无可用坐标`**：selector 在 hierarchy 无匹配；常是 Nexus fallback 给了 **不存在的 Tab 文案**。
- 少数：**坐标/ADB 时序**；看 `executor_used=adb` 与 hierarchy 是否 stale。
- **动作**：优先修 Nexus 给的 selector；Scout 侧加「失败回传 nodes 摘要」便于 Studio（若尚未有）。

### 5. 其他

- **LLM（volcengine lite）**：空 tool_calls、收工 thought 与屏不一致 → 换 model、调 prompt、或依赖 JSON 降级轮。
- **被测 App**：登录成功默认进拍摄、退出后 session 仍缓存等 → 产品/测试共识，非自动化单点 bug。

## 5. 建议优先级（跨类）

1. **用例/预期对齐**（1）：51 形象 vs 拍摄、c8cee 3D 文案、112 生成中阶段。  
2. **Nexus FSM fallback**（3）：口语 `to_state` 不得生成不存在 Tab；见 9/15 FSM 文档。  
3. **收工探针**（3）：详情/登录/退出 与 assert 共用同一 probe。  
4. **Provider**（5）：跑批 monitor `fail_kind=no_tool_calls`；必要时 agent-decide 对 volcengine 默认允许 tools 降级。  
5. **回归**：固定 5 case 批跑，对比 §3 表逐列消项。
