# 架构图混乱 — 问题清单与修复（2026-09-17）

## 现象

- 同一逻辑页拆成多个 `page.sk*`（缩放/后台卡片、搜索流子桶 `-s18/-s19`）。
- 画布上节点 **叠在一起**（同 x/y 或 y 对齐后列距不够）。
- **蓝线过密**（每条前进边再合成一条「返回」边 + 多热点出边）。
- 架构卡片线框与右侧 **采集预览** 差很大（两条管线）。
- orphan 桶（visit 极低）挂大量 nav 边，主桶空线框。

## 根因

| # | 根因 | 层 |
|---|------|-----|
| 1 | 桶内 split 用 **绝对坐标 Jaccard**，视口缩放帧先拆 `-sN` | Nexus 聚类 |
| 2 | 视口并页用 **空桶 merge_skeleton** 比线框，`same_page` 误判 | Nexus `_merge_wireframe_duplicate_clusters` |
| 3 | 并页被 **tap 出边签名** 误拦（orphan 有边、主桶无签名） | Nexus |
| 4 | Atlas 为无观测返回的 forward **自动补 synthetic back 边** | Nexus 建边 |
| 5 | `align_layout_y` 后 **未强制 `_resolve_layout_overlaps`**（块内多页） | Nexus 布局 |
| 6 | Studio 架构图 **from→to 重复线** + synthetic 返回线 | Studio |
| 7 | 采集预览 = hierarchy 全节点；架构 = **display 初始帧** + vision 过滤 | 产品预期 |

## 修复方向（本 PR）

1. `representative_wireframe_from_meta`：并页/比对用 turn 线框合成，不用空桶 wf。
2. 视口并页：`aligned ≥ 0.72` 或 orphan visit≤5 时 **不因 tap 签名拦截**；remap turn/边。
3. **停止** Atlas 自动 synthetic back；Studio 隐藏「有正向边时的合成返回线」。
4. 布局：块内列距随节点数放大；`align_*` 后 **必跑 overlap 推开**。
5. `split_indices`：视口 `same_page` 时并入同簇。

## 验证

- 重启 Nexus → 探索/刷新 Atlas → Studio 架构 Tab。
- 搜索流/用户信息区：`s18` 类 orphan 应并进主桶；边数约减半。
- 节点不应同坐标叠放（允许同行多列）。

## 后续（方案 A 对齐，2026-09-17）

- FSM augment：`_fsm_skeleton_remap_to_atlas_state` + 同车道 canonical，**不再灌无 layout 的 page.sk**；augment 后 **重跑 `enrich_atlas_doc`**。
- 布局：`_LAYOUT_ORPHAN_GAP=36`。
- Studio：架构 Atlas **恢复业务流块壳**（`buildFlowBlockShellNodes`）。

### P1（driver / 热点）

- `infer_driver_for_nav_edge`：标签「完成/自动」→ auto；Atlas 观测边默认 manual。

### Studio 快照（打开快 / 刷新重算）

- `GET /nav-fsm/{app_id}/screen-atlas` 默认读 `nav_fsm.meta.atlas_studio_snapshot`（完整 doc，含边 meta、线框、layout）。
- `rebuild=1` 或 Studio **「重新计算」**：全量 `build_atlas` 并更新快照。
- 无快照时首次请求仍会 build 并落盘。

### P2（块语义 / 可编辑分组）

- `_semantic_flow_block_name`：登录流/下单流/下载流/搜索流启发式块名。
- 布局收尾 `_resolve_layout_overlaps` gap 与 orphan 常量统一为 36。
