# 02 — 安装与分层产物

## 1. 为什么要分层

冻结包实测 ~1GB，其中 **browser（Chromium）占绝大部分**，**app（Scout 源码）每次发版都变**。  
分层后：**只改代码 → 只下 ~90KB 的 app 层**；browser 不变则不动。

| 层 | 安装位置（相对 `bin/`） | 指纹含义 |
|----|-------------------------|----------|
| **runtime** | `mino-scout`、`_internal/`、`runtime.lock` | PyInstaller 运行时 + **锁定 pip 依赖**（v0.1.28：`RUNTIME_ABI=3`） |
| **app** | `app/mino_scout/` | 版本号 + `requires_runtime=` 闸门 |
| **browser** | `ms-playwright/` | revision 目录名集合的哈希 |

**runtime 必须原子替换**：exe 与 `_internal` 同捆，不能只换一半。

真源：`MinoScout/scripts/layers.py`（与 `install.sh` / Studio `scoutLayers.cjs` 对齐）。

## 2. 发布物（GitHub Release）

每个平台条目在 `manifest.json` 的 `items[]` 里，通常包含：

| 产物 | 用途 |
|------|------|
| `MinoScout-{ver}-{os}-{arch}.zip` | **首次安装**：runtime + app（**不含** browser，加快上线） |
| `MinoScout-app-{ver}-…` | 仅 app 层增量 |
| `MinoScout-runtime-{rtkey}-…` | 仅 runtime |
| `MinoScout-browser-{bwkey}-…` | 仅 browser |

zip 根：`layers.txt` + 层目录 + `install.sh` / `install.ps1`。

## 3. 安装入口

### 3.1 Studio 本机（Electron）

1. `POST /runtime/nodes/install-token`
2. 拉 manifest，**`planScoutUpdate`**（与 Scout `install_plan.py` 同规则：browser 目录一致则跳过 browser 层等）
3. 逐层下载 → 解压 → **先 stop 再** 每层跑 `install.sh`
4. **再 start**，校验 PID 变化（app 层需新进程才加载）

见 MinoStudio `docs/SCOUT_INSTALL.md`。

### 3.2 远程一行命令（bootstrap）

- **macOS / Linux**：`packaging/bootstrap.sh`（`curl | bash`，参数 `--token` / `--nexus-url`）
- **Windows**：`packaging/bootstrap.ps1`

解析 manifest：**优先 jq**，无 jq 时用 python3。  
安装后写 `config.json`，注册 launchd / systemd / 计划任务。

### 3.3 禁止混淆的安装

- **不要**用旧 pip 包 `mino-scout 0.1.x` 当生产节点（子命令不全、与冻结包不是同一路径）。
- 生产二进制：`~/Library/Application Support/MinoScout/bin/mino-scout`（或 `~/.local/bin/mino-scout` 软链）。

## 4. 首次安装后的「重依赖」

合并包常 **不带 browser 层**。Scout **首次 REGISTER 后**后台线程跑 `heavy_deps`：

- 按 manifest 拉 **browser 层**（若需要）
- 准备 ADB Keyboard 等（策略见 Scout README；本系列不展开）

Nexus 侧应把「节点在线」与「Playwright 已就绪」区分：browser 未装完时 Web 用例可能 decline。

## 5. `layers.txt` 契约

**zip 内**（安装前读）：

```text
# 注释
runtime rt-xxxxxxxxxx
app 0.1.28 requires_runtime=rt-xxxxxxxxxx requires_browser=bw-…
browser bw-xxxxxxxxxx optional=1
```

**安装后**（`bin/layers.txt`，仅两列）：

```text
app 0.1.28
browser bw-xxxxxxxxxx
runtime rt-xxxxxxxxxx
```

`app-only` zip 安装前会 **check_app_gate**：本机 runtime 指纹必须等于 zip 里 `requires_runtime`。

## 6. 安装脚本行为（v0.1.28+）

- **替换**：`replace_path`（`.new` → `mv`，旧路径保留为 `.old`，**全部层成功后再删 .old**）。
- **失败**：`trap ERR` → 从 `.old` **回滚** + 恢复 `layers.txt` 快照。
- **权限**：`harden`（macOS `xattr -cr` + `chmod u+x`）；`self_update` 解压后对 `install.sh` 再 chmod。
- **CLI 链接**：`~/.local/bin/mino-scout` → 真实二进制（可用 `MINO_SCOUT_BIN_LINK_DIR` 覆盖）。
