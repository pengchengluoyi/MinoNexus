# 01 — 定位与系统边界

## 1. Scout 是什么

**MinoScout** 是跑在**执行专机**上的常驻 Agent：

- 反向连接 Nexus：`WS …/node`（不是 Nexus 去连设备）。
- 接收 `EXECUTE`，在本地通过 **executor**（adb、ios_wda、playwright 等）操作设备或 Web 槽位。
- 上报 `REGISTER` / `HEARTBEAT` / `RESULT`，以及框架事件（设备上下线、更新进度等）。

Nexus 是**大脑**：用例循环、派单、资源与账号都在 Nexus；Scout 是**手脚**。

## 2. 四个角色

| 角色 | 职责 | Scout 相关 |
|------|------|------------|
| **MinoNexus** | 跑批、路由、节点登记、下发 `node.stop/restart/update` | `NodeRegistry`、`/runtime/nodes`、WebSocket `/node` |
| **MinoScout** | 设备探测、执行、本机安装/更新 | `bin/mino-scout run`、launchd / 计划任务 |
| **Mino Studio** | 发安装 token、本机分层安装、远程更新 UI | Electron `scout-setup`、GitHub manifest |
| **Mino Console** | 全局节点/资产视图（管理员） | 读同一套 `/runtime/assets` |

安装凭证：`POST /runtime/nodes/install-token` 只发 **token + nexus_url**；**zip 永远从 GitHub 拉**。

## 3. 节点与设备（业务模型）

```
node_id（= scout_id，16 位字母数字）
  └── devices[]
        ├── Android serial（adb + 可选 remote）
        ├── iOS UDID（WDA）
        └── web{node_id}（Playwright 虚拟槽，每节点一个）
```

- **归属**：REGISTER/HEARTBEAT 写入；节点离线 **45s** 后设备标 disconnected，**不删归属**（避免 UI 闪灭）。见 [NODE_REGISTRY.md](../基础框架/NODE_REGISTRY.md)。
- **Web 用例**：Nexus 把 `sn` 设为 `web…`，router 只派 **playwright** 通道；与真机 executor 互斥。

## 4. 循环如何「看不见 Scout」

`mino_nexus/loop/router_proxy.py` 把能力调用序列化成 `EXECUTE` 发给已连接节点。  
`agent_loop` / `recovery` **不得**写 `if scout_connected` —— 网络是 RouterProxy 的事（CLAUDE.md §2.2）。

留在 Nexus 本地的 executor：`hitl`、`vlm`、`ai_persona`、`internal`（wait/noop）。

## 5. 配置真源（专机侧）

| 路径（macOS 用户安装） | 内容 |
|------------------------|------|
| `~/Library/Application Support/MinoScout/config.json` | `nexus_url`、`token`、`version`、`manifest_url`（可选）、`installed_layers`（更新后） |
| `…/bin/layers.txt` | 已装三层指纹：`runtime` / `app` / `browser` |
| `…/bin/mino-scout` + `_internal/` | runtime 层 |
| `…/bin/app/mino_scout/` | app 层（纯 Python，可热更） |
| `…/bin/ms-playwright/` | browser 层（Chromium，体积大） |
| `~/Library/Logs/MinoScout/scout.log` | 标准输出 |

配对：**REGISTER 带 token**；Nexus 校验 install token / node credential 后接受。

## 6. 与上游 MiniOrangeServer 的差异

| 上游 | 拆分后 |
|------|--------|
| 单进程 + 本地 adb | Nexus 无 adb；Scout 独占设备栈 |
| `sn` 即连接 | 显式 `node_id` + 多节点派单 |
| 服务端打包一切 | Scout 独立 Release、分层更新 |

搬迁映射见 MinoScout `docs/MIGRATION.md`（只读参考，不在本仓改上游）。
