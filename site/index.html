03 / 三步完成

从下载到打开，只需几步

01 — 获取安装器

下载文件或复制命令

Windows 可直接运行 EXE。macOS / Linux 推荐复制一键安装命令到终端，脚本会下载并校验对应安装器。

02 — 安装组件

选择 Nexus、Workbench 或两者

一键命令使用上方选中的组件；直接下载的安装器会再显示组件菜单。默认安装到用户目录下的 Mino 文件夹。

03 — 开始使用

打开 Workbench

Workbench 安装成功后会自动打开浏览器。以后运行 mino-workbench open 即可打开，也可访问 http://127.0.0.1:60104。无桌面的服务器安装可添加 --no-open。只安装 Nexus 时，可从其他已配置的 Workbench 连接。

下载的文件从哪里来？

来自项目的 GitHub Releases。安装包由 GitHub Actions 在对应系统上编译、验收并发布。安装脚本校验安装器的 SHA256，安装器继续校验组件包的大小和 SHA256。无需在你的电脑上安装 Python、Node.js 或 GitHub CLI。

如何复制、分享下载链接？

选择操作系统后，点击“复制下载链接”。如果浏览器不允许读取剪贴板，页面会选中直链文本，你可以手动复制。链接始终指向最新正式安装器，接收方应使用同一种系统与处理器。

macOS 的两个版本怎么选？

在苹果菜单 →“关于本机”查看：芯片为 Apple M 系列时选 Apple Silicon；处理器为 Intel 时选 Intel。不要仅凭浏览器自动检测判断处理器。当前 Linux 和 Windows 安装包支持 x64，不包含 ARM64。

已有安装、端口被占用，或需要开机自启？

安装器会停止并保留已有数据，不覆盖现有安装，也不自动更换端口。已有实例请使用维护入口升级。Linux / Windows 当前以用户后台进程运行，尚不注册开机自启。

测试环境和 Scout 在哪里？

这里仅提供正式安装。开发测试从源码 / PyCharm 启动：Nexus 50101，Workbench 60101。Scout 不需要独立业务监听端口，只连接相应 Nexus；本安装器不包含 Scout。前往 Scout 仓库 ↗
