MINO / 部署与下载

一个服务，一个工作台。

Nexus 内置 Workbench。浏览器访问 Nexus 的 50104 端口，即可使用完整界面。

macOS · wheel + launchd

从 Release 下载内置 Workbench 的 wheel，并核对 SHA256。需要 Python 3.12 或以上及 pipx。

pipx install ./mino_nexus-X.Y.Z-py3-none-any.whl
mino-nexus service install
mino-nexus service status

将 X.Y.Z 替换为实际发布版本，打开 http://127.0.0.1:50104/。

查看产品 Release 与校验清单

Linux · Docker

支持 AMD64 与 ARM64；镜像内为同一产品 wheel，使用独立数据卷。

export MINO_NEXUS_VERSION=X.Y.Z
docker compose pull
docker compose up -d

在 Compose 文件所在目录执行，指定具体版本。Release 同时提供分架构离线镜像包。

Scout · 设备执行节点

Scout 单独安装在连接设备的机器，不放进 Nexus 容器。连接 ws://服务器:50104/node；无需安装独立 Workbench。

升级与已有安装

升级使用新 wheel 或固定镜像 tag，页面不再执行在线自更新。升级前停写并备份；自动迁移前备份当前暂未实现。旧安装目录保留，迁移需复制到新目录后验收，不能直接覆盖业务库。

完整部署、升级与回滚说明

若 Release 尚无 wheel 或镜像附件，请等待对应版本发布；不要将旧原生安装包当作合并部署产物。

开发环境：Nexus 50101 / Workbench 60101。正式环境：单一 50104。
